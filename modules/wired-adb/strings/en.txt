name=Wired ADB
summary=Connect to ADB from a Mac over a USB cable.
import_key=Import ADB key from USB
import_key_confirm=Read HSM/adbkey.pub from the USB drive and allow those computers to connect? Keys imported before are replaced.
clear_key=Remove ADB keys
clear_key_confirm=Remove every imported ADB key? No computer can connect until a key is imported again.
no_key_warning=No ADB key is imported yet. No computer can connect.
key_count=Imported ADB keys
link_state=Cable link
endpoint=ADB endpoint (IPv4)
endpoint6=ADB address (IPv6 link-local)
key_note=Copy ~/.android/adbkey.pub from the computer to HSM/adbkey.pub on a USB drive, plug it into the car and choose Import ADB key from USB. One key per line, 8 at most.
key_adb_note=Over wireless ADB, root can write the same key lines to /data/nemesis/backup/hmg-seogaemo/modules/wired-adb/adb_keys instead. A connected Mac uses them after this is turned off and on.
connect_note=Plug the Mac into a data USB port of the car and run adb connect 192.168.2.249:5556. This address needs Internet Sharing on the Mac.
connect_v6_note=Without Internet Sharing use the IPv6 address with the Mac's interface name, for example adb connect "[fe80::c7ad:b%en5]:5556".
security_note=Only computers whose key was imported can connect, and only over the cable. Stock ADB and its settings are not changed.
restore_note=Turning this off stops the cable service. Imported keys stay until they are removed or HMG-Seogaemo is uninstalled.
on_result=After its key is imported, a Mac on the car's USB port can connect to ADB on port 5556.
off_result=The cable service stops. Nothing else on the unit was changed.
